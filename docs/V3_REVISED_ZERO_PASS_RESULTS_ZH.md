## 成功轨迹的语义审核

### 可保留的3道

1. **研发费用增长率**
   - 工具公式：`((76981-61975)/61975 + (101151-76981)/76981)/2`
   - 工具返回：`0.2780517344904797`
   - final：`27.81%`
   - 结论：小数增长率正确换算为百分数，路径有效。
2. **相邻两年收入均值变化**
   - 工具公式：`(1552691+1470797)/2 - (1470797+1388290)/2`
   - 工具返回及final：`82200.5`
   - 结论：公式、工具结果、final和GT完全一致。
3. **平均租金费用金额**
   - 工具公式：`(4482+785+0+0+0)/5`
   - 工具返回及final：`1053.4`
   - 结论：修正符号约定后路径完全一致。

### 拒绝的1道

**考试正确题数之差**虽然final `3`通过GT，但轨迹先调用计算器得到：

```text
(75-15)-(75-12) = -3
```

随后final无解释地改成`3`。最终答案可以解释为“少3题”的正数幅度，但该工具公式的
方向与题面不一致，且工具结果与final不一致。它不能作为工具调用SFT轨迹，应该用
`(75-12) - 75*(1-0.20) = 3`重新构造参考轨迹。
