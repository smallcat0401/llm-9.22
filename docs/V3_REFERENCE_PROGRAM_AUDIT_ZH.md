## 这批数据是什么

初始 27 条候选不是 4B 模型通过 Best-of-8 找到的成功答案，而是为可信的零通过训练题人工编写的参考程序：

```text
英文原题与表格

  → 安全计算器真实执行
  → 按题目要求整理 final 数值
  → verifier 与 GT 比较
  → 生成 native tool-call SFT 对话
```

因此它们只能称为 **reference-program SFT**，不能称为搜索蒸馏数据。单题复测闭环后，32 条 Search-SFT 候选与当前 26 条 reference-program 数据必须继续分开记录。

3. 实测 pass@1 为 0/1，pass@8 为 1/1；
4. 成功轨迹使用正确公式，工具返回 `-33.82902825746931`，final 输出 `-33.8`；
5. 因为路径完全对齐，新版本进入 Search-SFT，原始歧义版本和人工参考轨迹都不进入当前训练集。
